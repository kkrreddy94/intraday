# NSE & BSE Intraday Trading & Dashboard System

High-end Python algorithmic trading engine designed for the Indian Stock Market (Nifty 50, Bank Nifty, Sensex). Implements institutional indicator strategies (VWAP, RSI, EMA, MACD, Bollinger Bands)[cite: 3, 15], real-time RSS market news filtering from reliable reporting agencies, and an interactive Streamlit dashboard.
